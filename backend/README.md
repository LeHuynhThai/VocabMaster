# VocabMaster Backend

## Structure

- `src/VocabMaster.Domain`: domain entities, base types, and repository contracts.
- `src/VocabMaster.Application`: application services and cross-layer abstractions.
- `src/VocabMaster.Infrastructure`: EF Core persistence, repositories, seed data, and identity implementation.
- `src/VocabMaster.Api`: ASP.NET Core entry point, controllers, and middleware.
